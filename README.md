# Meta Rolls

Browse your photo library and build albums.

A desktop app (Electron + React) for browsing a local photo library and assembling albums.

## Recommended IDE Setup

- [VSCode](https://code.visualstudio.com/) + [oxc](https://marketplace.visualstudio.com/items?itemName=oxc.oxc-vscode)

## Project Setup

### Install

```bash
$ pnpm install
```

### Development

```bash
$ pnpm dev
```

### Build

```bash
# For windows
$ pnpm build:win

# For macOS
$ pnpm build:mac

# For Linux
$ pnpm build:linux
```
